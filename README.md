# EURO TRADE

مشروع واحد بـ TypeScript، بديل التلات مشاريع القديمة (`euro_trade` + `euro_trade_admin` + `euroapp`).

```
apps/
  web/       تطبيق المستخدم + لوحة التحكم  (Next.js)
  mobile/    قشرة الموبايل                (Capacitor — بديل euroapp)
  worker/    كاش Cloudflare
packages/
  engine/    محرك الإشارات — 8 مؤشرات (عيلة الفيبوناتشي) + جمع نقاط
  shared/    أنواع الداتابيز + Supabase + اللغة + الثوابت
tools/
  golden-dart/  مسجّل مرجع التطابق من محرك Dart الأصلي
```

## التشغيل

```bash
npm install
npm --workspace @euro/web run dev     # http://localhost:3000
```

| المسار | |
|---|---|
| `/` | البداية |
| `/app` | شاشة التداول |

## المحرك — إيه اللي فيه دلوقتي

المحرك هو الحتة اللي بتقرر CALL/PUT. أي فرق فيه = إشارات مختلفة للعملاء.

```bash
npm run verify          # ده اللي بيشغّل كل حاجة
```

**الاستراتيجيات برامج مثبّتة في المحرك، مش ملفات بتترفع.** كل خطة (مجانية /
مدفوعة) بتشاور على برنامج في `packages/engine/src/programs/` — الحالي هو
`fib_236_touch` للاتنين. تغيير استراتيجية خطة = سطر في `programs/index.ts`
وديبلوي. مفيش رفع ولا تعديل أونلاين.

**تمن مؤشرات** لسه موجودة للبرامج اللي محتاجاها:

`fib_retracement` · `fib_extension` · `fib_distance` · `fib_level` · `fib_zone` ·
`fib_bounce` · `sr_position` · `sr_bounce`

كلهم مرسومين من سوينج واحد: أحدث **intermediate high** وأحدث **intermediate
low** — القمة اللي القمتين اللي حواليها ما وصلوش لها، والقاع بالعكس. البحث على
آخر 100 شمعة، وهي كل اللي الفيد بيديه. مفيش سوينج مؤكَّد في 13.3% من الشموع،
وساعتها الأرقام بترجّع -1 والنصوص بترجّع `none`.

**الحساب:** كل قاعدة شرطها صح بتضيف `score` لناحيتها، والناتج = CALL ناقص PUT،
والبوّابة الوحيدة `min_score` على القيمة المطلقة.

**اللي اتشال:** الهرم بالكامل (الفئات، مضاعف الإجماع، محور التأكيد، الفلاتر،
`min_primary_score`)، ومصفوفة الارتباط والمعايرة، و231 مؤشر. `role` و `type`
لسه بيتقروا من ملف الاستراتيجية لكن **المحرك بيتجاهلهم**.

### التطابق مع Dart — اللي فاضل منه

بوّابة الـ359 مؤشر راحت مع المؤشرات نفسها: مفيش قيم فاضلة تتقارن. اللي فاضل:

- المسجّل البارامتري V2 (19 اختبار) — وده بيشتغل بس لما مافيش استراتيجية مرفوعة
- `checkCondition` — اتنقل من `pyramid/conditions.ts` من غير أي تغيير في سطر واحد
- اختبارات الفيبوناتشي والدعم/المقاومة (22 اختبار على شموع مبنية بالإيد)

الدوال الحسابية في `indicators/math.ts` و `structure.ts` و `patterns.ts` لسه
موجودة، بس **مش متسجّلة** — بتغذّي الـ12 مرحلة تحليل اللي الزرار بيعرضها،
والمسجّل البارامتري. أي قاعدة بتسمّي واحد منهم بترجّع 0.0 زي أي اسم غلط.

### الباك تست

من لوحة التحكم → الاستراتيجيات: تختار الخطة، وهو بيشغّل **نفس البرنامج** اللي
التطبيق بيشغّله على كل التاريخ المتاح، شمعة بشمعة، بنفس قواعد عدم الـrepainting
وبنفس التسوية وبنفس المضاعفة.

قيد حقيقي: الفيد بيحتفظ بـ**100 شمعة بس** لكل زوج، فعلى فريم دقيقة العيّنة
بتطلع ساعة وسبعة وثلاثين لكل زوج — عشرات الصفقات مش مئات. الرقم بيتقري على إنه
مؤشر مش حكم، والباك تست نفسه بيرفض يحكم تحت 30 صفقة محسومة.
