# @euro/admin-mobile — تطبيق لوحة التحكم

تطبيق منفصل للأدمن، بيفتح **نفس الموقع المنشور** على `/admin`.

## ليه تطبيق تاني مش شاشة جوه تطبيق المستخدم

- الأدمن ماينفعش يبقى مسار مخفي جوه تطبيق بيتوزّع على الناس
- معرّف مختلف (`com.eurotrade.admin`) = أيقونة مستقلة في اللانشر
- لون مختلف (`#030712`) زي ما الشاشات نفسها متفرقة، فمستحيل تلخبط بينهم

## مفيش كود مكرّر

اللوحة موجودة أصلاً جوه تطبيق الويب. الملف ده كله اللي بيعمل «تطبيق الأدمن» —
مفيش build تاني ولا نسخة تانية من أي شاشة.

## بعيد فقط

اللوحة أداة تشغيل: كل شاشة فيها بتقرا من Supabase، يعني من غير نت مفيدة بصفر
الحالات. فالتحميل من الموقع المنشور مباشرة معناه إن أي إصلاح يوصلك ساعة ما
يتنشر، من غير APK جديد.

## البناء

```bash
npx cap add android          # أول مرة فقط
npm --workspace @euro/admin-mobile run sync
cd android && ./gradlew assembleDebug
```

الأيقونات بتتولّد من `assets/` بـ:

```bash
npx capacitor-assets generate --android \
  --iconBackgroundColor '#030712' --splashBackgroundColor '#030712'
```
